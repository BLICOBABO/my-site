# my-site

我的个人主页

## 目录结构

```
my-site/
├── index.html          # 首页（入口）
├── pages/              # 站内页面
│   ├── resume.html     # 简历
│   ├── works.html      # 作品
│   ├── articles.html   # 文章列表
│   ├── quantified.html # 量化自我
│   └── review.html     # 年度回顾
├── articles/           # 文章正文
│   ├── post1.html
│   └── post2.html
└── assets/             # 静态资源
    ├── css/            # 样式
    ├── js/             # 脚本（二进制雨、终端打字）
    └── images/         # 图片
```
